## 三、關鍵發現

### 🏆 發現 1: deepseek-v4.1-flash 是目前最佳即時判讀模型

```
輸入: "小計 NT$3,580，折扣 NT$0，總額 NT$3,580，預期折抵 NT$500"
輸出: "折扣失效 100"
時間: 0.84s
```

✅ **時間極快**（0.84s，比目標 3s 快 3 倍）
✅ **內容正確**（正確識別「折扣失效」）
✅ **格式可解析**（「異常類型 + 信心分數」= 接近 JSON）
✅ **成本低**（僅需 80–150 tokens）

### ⚠️ 發現 2: 多數模型 content 欄位仍為空

與 kimi-k2.6 相同，glm、kimik3、mistral 等模型的 `content` 皆為空，輸出全在 `reasoning`。

**但 deepseek-v4.1-flash 和 nemotron-3-nano 能正確輸出到 content！**

這表示 Ollama Cloud 對不同模型的「reasoning」配置不一致：
- DeepSeek / NVIDIA Nemotron：content + reasoning 雙欄位輸出
- Kimi / GLM / Mistral：僅 reasoning 單欄位

### 🟡 發現 3: mistral-large-4 基本對話超慢

29.35s 回應時間，表示此模型不適合任何即時應用，只能做離線分析。
