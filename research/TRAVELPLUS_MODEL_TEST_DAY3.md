## 測試結果

### Qwen 2.5 7B（導航測試）
- **TTFT**：約 2.5 秒
- **成功率**：60%
- **步驐數**：5 步（訪問首頁 → 選擇產品 → 選擇顏色 → 選擇尺寸 → 加入購物車）
- **Token 消耗**：約 3,200 tokens（輸入）/ 1,800 tokens（輸出）
- **成本**：免費（本地部署）
- **優點**：
  - 正確識別 `#putinCart`（放入購物車）和 `#goShoppingCart`（立刻結帳）按鈕
  - 能理解顏色/尺寸選擇邏輯（需先選顏色再選尺寸）
- **缺點**：
  - 面對 ASP.NET 客製化 `<select>` 時，無法正確模擬選擇動作
  - 在處理複雜表單驗證時會出現延遲

### Gemma 3 4B（導航測試）
- **TTFT**：約 1.8 秒
- **成功率**：40%
- **步驐數**：4 步（訪問首頁 → 選擇產品 → 嘗試選擇顏色 → 加入購物車）
- **Token 消耗**：約 2,800 tokens（輸入）/ 1,500 tokens（輸出）
- **成本**：免費（本地部署）
- **優點**：
  - 能夠正確定位「放入購物車」按鈕
  - 響應速度較快
- **缺點**：
  - 處理價格比較（定價 NT:13800 vs 特價 NT:8080）時出現混淆
  - 無法理解「索取折價券」僅為客服連結而非結帳折扣碼輸入
  - 決策準確度有限

## 發現的問題或驚喜

### 問題
1. **Ollama Cloud API 金鑰有效性仍無法確認**：`.env` 中 `OLLAMA_API_KEY=***` 已存在，但無法確認是否有效
2. **TravelPlus 無折扣碼機制**：「索取折價券」僅為 LINE 客服連結，非結帳折扣碼輸入，CartRescue 測試目標需調整
3. **ASP.NET 客製化 UI**：顏色/尺寸選擇器非標準 `<select>`，而是客製化按鈕，增加自動化難度

### 驚喜
1. **Qwen 2.5 7B 能理解中文語境**：在處理繁體中文產品頁時表現良好
2. **Gemma 3 4B 響應速度快**：雖然準確度有限，但 TTFT 僅 1.8 秒

## TravelPlus 網站結構分析（Day 3 更新）

### 產品頁結構
- **產品名稱**：AZPAC 26吋 Trucker 3.0 前開行李箱 7:3半開 防爆拉鍊 靜音輪 胖胖箱
- **定價**：NT:13800（特價：8080）
- **款式**：Az00026
- **品牌**：AZPAC
- **顏色選擇**：曜石黑、薄暮灰、月牙藍、松針綠（客製化按鈕）
- **尺寸選擇**：26吋（客製化按鈕）
- **放入購物車**：`#putinCart`
- **立刻結帳**：`#goShoppingCart`
- **索取折價券**：LINE 客服連結（非折扣碼輸入）

### 結帳流程
1. 未登入會員時，點擊「立刻結帳」會重定向到 `login.aspx`
2. 需先登入會員才能進入結帳頁面
3. 無折扣碼輸入欄位
