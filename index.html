折扣碼失效原因分析 (SimplyCodes 7880萬次實測)

獨特切角：折扣碼失敗率達 26.2%。35% 為過期未下架、28% 為隱藏限制條件—多數屬商家後台「設定錯誤」，可被自動巡檢攔截。

真實痛點案例：DTC 保養品牌疊加 Bug 事故

一 DTC 保養品牌因後台折扣碼可「違規疊加」的設定 Bug，單一週末遭大量洗單，損失約 6.3 萬美元毛利。CartRescue AI 的 KOL/折扣碼批量審計能自動阻斷此類漏洞。

⑦ 即時警報 高信心事件即時推送 LINE / Slack

生產化核心設計決策

  • 控制與執行分離: n8n 只負責調度，Worker 無狀態可水平擴展。
  • 多租戶 Row Level Security (RLS): 站點與審計日誌按租戶隔離，商業化免重構。
  • 模型分流 (LLM Cost Control): 導航使用輕量模型 (GPT-4o-mini)，僅異常判讀使用旗艦模型。

風險與防護機制

WAF / Bot 攔截防護: 僅審計簽約商家，將審計 IP 加入白名單並提供測試帳號。
防止測試訂單污染: 模擬推進至付款頁即停止扣款，使用專用測試 SKU / 折扣碼。
降低誤報損害信任: 異常先自動重跑二次確認，僅高信心分數事件觸發即時警報。
