### 2. 三模型異常判讀測試（新網站 — 🔴 全軍覆沒）

#### Qwen2.5:7b

| 項目 | 結果 | 正確性 |
|------|------|--------|
| 原價推斷 | 4,100 元（將促銷價視為原價） | ⚠️ 可能正確但不確定 |
| 折扣率計算 | 3,390 / 4,100 ≈ 82.68%（聲稱「82.68% 折扣」） | ❌ **錯誤**——實際是 17.32% off，模型混淆了「折扣率」與「剩餘比例」 |
| 促銷衝突分析 | 聲稱「沒有衝突」 | ⚠️ 過於樂觀 |
| moPro會員分析 | 聲稱「價格差異合理」 | ⚠️ 未深入分析 |
| **風險等級** | 🟢 **Low** | ⚠️ 可能低估 |
| 時間 | **80.80s** | |

> **問題**：Qwen 將 3,390/4,100 = 0.8268 解讀為「82.68% 折扣」，但實際折扣率是 (4,100−3,390)/4,100 = **17.32%**。模型混淆了「剩餘價格比例」與「折扣幅度」。

#### Gemma3:4b

| 項目 | 結果 | 正確性 |
|------|------|--------|
| 原價推斷 | 4,100 + 3,390 = **7,490 元** | ❌ **災難性錯誤**——將兩個價格相加作為原價 |
| 折扣率計算 | 基於 7,490 元計算，得出錯誤結果 | ❌ 基礎錯誤導致全盤皆錯 |
| 促銷衝突分析 | 部分正確（指出部分優惠條件與產品不符） | ✅ 有一定價值 |
| moPro會員分析 | 指出優惠條件模糊 | ✅ 有價值 |
| **風險等級** | 🟡 **Medium** | ✅ 相對合理 |
| 時間 | **67.12s** | |

> **災難性錯誤**：Gemma 將「促銷價 4,100」+「折後價 3,390」= 7,490 元視為原價，這是完全錯誤的商業邏輯。兩個價格是「前後關係」而非「相加關係」。

#### Llama3.2:3b

| 項目 | 結果 | 正確性 |
|------|------|--------|
| 原價推斷 | 4,100 / 9 = **455 元** | ❌ **極度錯誤**——將「9折」誤解為「除以9」 |
| 折扣率計算 | (455 − 3,390) / 455 = −6.47（負數） | ❌ 完全無意義 |
| 重算後 | 4,100 / 0.91 ≈ 4,500 元 | ⚠️ 嘗試修正但仍不正確 |
| 促銷衝突分析 | 指出可能存在衝突 | ✅ 有價值 |
| **風險等級** | 🟥 **High** | ✅ 直覺正確，但推理全錯 |
| 時間 | **44.30s** | |

> **極度錯誤**：Llama 將「9折」理解為「除以 9」而非「乘以 0.9」，導致原價被推斷為 455 元（比折後價還低）。雖然最終結論「High Risk」直覺正確，但**推理過程完全不可信**。

## 發現的問題或驚喜

### 🎉 驚喜

1. **導航任務完美泛化**：三模型在全新網站（momo）上全部正確選擇「放入購物車」，證明結構化 Prompt 的導航能力具備**跨網站泛化性**。
2. **Gemma 速度持續領先**：在新網站上仍保持 4.10s 的導航速度，比 Qwen 快 44%。

### ⚠️ 重大問題（🔴 首次發現）

1. **複雜促銷結構導致三模型異常判讀全軍覆沒**：
   - TravelPlus（單一定價/特價/VIP價）：模型可正確計算
   - momoshop（9折 + 滿額折 + 回饋點數 + 會員專屬 + 贈品）：**三模型均出現計算錯誤**
   - **核心問題**：小模型無法理解「多層級促銷疊加」的商業邏輯

2. **模型對「折扣術語」的理解存在根本性偏差**：
   - Qwen：混淆「剩餘價格比例」與「折扣幅度」
   - Gemma：將兩個價格相加作為原價
   - Llama：將「9折」理解為「除以9」
   - **這不是隨機錯誤，而是結構性理解缺陷**

3. **多數投票機制在複雜場景下失效**：
   - TravelPlus：三模型可達成 Medium 共識
   - momoshop：Low / Medium / High 全不一致
   - **結論**：當單一模型推理不穩定時，多數投票無法產生有意義的共識

4. **連續 14 天無法測試雲端模型**：OpenAI / Anthropic / Gemini / Moonshot API 金鑰仍缺失。
