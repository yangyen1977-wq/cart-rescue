## 1. 執行摘要

CartRescue AI 的核心工作負載分為兩類：
1. **頁面導航**（5–8 步）：理解網頁結構、決定點擊目標、填寫表單 → 需要 **低成本、低延遲**
2. **異常判讀**（1–2 次）：分析截圖與頁面內容，判斷 Bug/錯誤/流程阻斷 → 需要 **高準確度、強視覺理解**

本報告比較 **20+ 個模型**（含最新 2026 年 Q3 發布的旗艦模型），建立單次審計成本模型、三方案月成本預測，並提出「混合路由」策略。

**核心結論**：
- **最佳混合路由**：導航用 **Gemini 2.0 Flash**（$0.075/M input），異常判讀用 **Gemini 2.0 Pro**（$1.75/M input）
- **單次審計最低成本**：$0.0088（全 Gemini-2.0-Flash）至 $0.0416（Flash + Pro 混合）
- **Enterprise 月成本**：全旗艦方案約 $11,854/月 → 混合路由方案約 $2,089/月，**年省 $117,000+**

## 3. 新模型詳細分析

### 3.1 Claude Opus 4.8 — Computer Use 之王

**為什麼最適合瀏覽器自動化**：
- OSWorld 基準 **87.1%**（業界最高）
- 極少的操作錯誤，最適合「晚上無人值守自動審計」
- 200K context window，可容納完整網頁 HTML

**成本**：$5 input / $25 output per MTok
- 單次審計（102K input + 2.9K output）：**$0.585**
- 是 Gemini Flash 的 **66 倍**

**建議**：僅用於極少數「高風險審計」（如 Enterprise 客戶的大促前最終檢查）

---

### 3.2 Claude Sonnet 5 — 最佳平衡點

**為什麼推薦**：
- Intro 定價 $2/$10，僅 Opus 4.8 的 **40% 價格**
- Standard $3/$15，仍只有 Opus 的 **60%**
- SWE-bench 85.2%，幾乎與 Opus 同級
- 延遲 600ms，比 Opus 快一倍

**成本**：
- Intro：單次審計 **$0.233**
- Standard：單次審計 **$0.350**

**建議**：作為「異常判讀」的主力模型，取代 Claude 3.5 Sonnet

---

### 3.3 GPT-5.5 / GPT-5.6 Sol — OpenAI 最新旗艦

**能力**：
- GPT-5.5：$5/$30，與 Claude Opus 並列頂尖
- GPT-5.6 Sol：$5/$25（標準版），$4/$20（low 版）
- 原生多模態 + function calling + 結構化輸出
- 適合複雜網頁的語義理解

**成本**：
- GPT-5.6 Sol (low)：單次審計 **$0.466**
- GPT-5.6 Sol：單次審計 **$0.582**

**建議**：不推薦用於 CartRescue，成本過高，性價比不如 Claude Sonnet 5

---

### 3.4 Gemini 3.1 Pro / Flash — Google 最新世代

**為什麼重要**：
- Gemini 3.1 Pro：$2/$12，比 GPT-5.5 便宜 **60%**
- Gemini 3.1 Flash：$0.50/$3，比 GPT-4o-mini 稍貴但能力更強
- 1M context window，業界最大
- 原生 audio/video 支援（未來可擴展到影片審計）

**成本**：
- Gemini 3.1 Pro：單次審計 **$0.239**
- Gemini 3.1 Flash：單次審計 **$0.060**

**建議**：
- Gemini 3.1 Flash 可替代 Gemini 2.0 Flash 作為導航模型（能力更強）
- Gemini 3.1 Pro 可作為異常判讀的升級選項

```
                          ↓

│ 升級：Claude Sonnet 5 ($0.233)                 │

```

### 6.2 信心分數路由邏輯

```python
# 偽代碼
if confidence_score >= 0.9:
    # 高信心：用最便宜模型二次確認
    model = "gemini-2.0-flash"
elif confidence_score >= 0.7:
    # 中高信心：用 Sonnet 5 確認
    model = "claude-sonnet-5"
else:
    # 低信心：用 Opus 4.8 深度分析
    model = "claude-opus-4.8"
```

### 6.3 成本優化技巧

1. **截圖壓縮**：將截圖從 8K tokens 壓到 4K，成本降 50%
2. **快取重複頁面**：相同網頁結構的快取，避免重複分析
3. **Batch API**：使用 OpenAI/Anthropic 的 Batch API（半價）處理非即時審計
4. **Off-peak 排程**：利用 DeepSeek off-peak 半價時段處理低優先級審計
5. **Prompt Caching**：利用 Claude/Kimi 的 prompt cache 降 70% 重複輸入成本
