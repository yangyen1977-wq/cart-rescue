## Unit Economics（單位經濟模型）

### 定義單位
**1 單位 = 1 個付費網站 / 每月**

### 單位收入（ARPU）

| 方案 | 月費（USD） | 目標佔比 | 加權 ARPU |
|------|------------|----------|-----------|
| Starter | $49 | 40% | $19.60 |
| Pro | $149 | 45% | $67.05 |
| Enterprise | $499 | 15% | $74.85 |
| **加權平均 ARPU** | | | **$161.50/月** |

### 單位成本（COGS）

| 成本項目 | 每網站/月 | 說明 |
|----------|-----------|------|
| LLM API（GPT-4o + Claude） | $12 | 每日 2-4 次巡檢，含圖片分析 |
| 代理 IP（Bright Data） | $5 | 住宅代理輪替 |
| 雲端基礎設施（Supabase + R2） | $8 | 資料庫 + 儲存 + 頻寬 |
| n8n 執行成本 | $2 | self-hosted 攤提 |
| **總 COGS** | **$27/網站/月** | |

### 單位經濟指標

```
ARPU（月均收入）          = $161.50
COGS（月均直接成本）       = $27.00
────────────────────────────────────
Gross Margin（毛利率）     = $134.50（83%）

CAC（客戶獲取成本）        = $200（估計，含行銷+銷售）
LTV（客戶終身價值）         = $161.50 × 18 個月（預估留存）× 毛利率 83%
                          = $2,414

LTV:CAC 比率               = 2,414 : 200 = 12:1
Payback Period（回本週期）  = $200 / $134.50 ≈ 1.5 個月
Monthly Churn（月流失率）    = 5%（目標，Phase 1）→ 3%（Phase 2）
Annual Churn（年流失率）     = 46% → 31%
```

### 規模經濟效應

| 網站數 | 總收入/月 | 總 COGS/月 | 毛利率 | 備註 |
|--------|-----------|-----------|--------|------|
| 10 | $1,615 | $270 | 83% | MVP 驗證期 |
| 100 | $16,150 | $2,200 | 86% | 基礎設施攤提開始 |
| 500 | $80,750 | $9,500 | 88% | LLM batch 優化生效 |
| 1,000 | $161,500 | $16,000 | 90% | 代理議價、基礎設施規模化 |
| 5,000 | $807,500 | $65,000 | 92% | 企業級效率 |

### 損益平衡分析

```
固定成本/月（Phase 1）:
- 工程團隊（3 人 × $5,000）    = $15,000
- 基礎開支（辦公室、工具等）      = $2,000
- 行銷（內容 + 社群）            = $3,000
────────────────────────────────
總固定成本                        = $20,000/月

損益平衡點 = $20,000 / $134.50 ≈ 149 個付費網站

→ 達到 150 個網站即損益平衡
→ 500 個網站時月利潤 ≈ $47,250
→ 1,000 個網站時月利潤 ≈ $114,500
```

## 收入模式與定價策略

### 定價哲學
**「價值定價，而非成本定價」** —— 客戶付的不是巡檢次數，是「不再流失的收入」。

### 三級定價方案

#### Starter — $49/月
**目標**：DTC 品牌 / 小型電商（年營收 < $500K）

| 項目 | 限制 |
|------|------|
| 監控網站數 | 1 |
| 每日巡檢次數 | 2 |
| 折扣碼數量 | 5 |
| 通知渠道 | Email + Slack |
| 自動修復 | ❌ 僅建議 |
| 歷史記錄保留 | 30 天 |
| 支援 | 社群 + 文件 |

#### Pro — $149/月（主推方案）
**目標**：成長型電商（年營收 $500K-$5M）

| 項目 | 限制 |
|------|------|
| 監控網站數 | 3 |
| 每日巡檢次數 | 8（每站） |
| 折扣碼數量 | 20/站 |
| 通知渠道 | Email + Slack + Discord + Webhook |
| 自動修復 | ✅ n8n 整合 |
| 歷史記錄保留 | 90 天 |
| 每週報告 | ✅ |
| 支援 | 優先郵件支援 |
| 自定義巡檢步驟 | ✅ |

#### Enterprise — $499/月起
**目標**：中大型品牌 / Agency（年營收 > $5M）

| 項目 | 限制 |
|------|------|
| 監控網站數 | 無限 |
| 每日巡檢次數 | 自定義 |
| 折扣碼數量 | 無限 |
| 通知渠道 | 全部 + 自定義 |
| 自動修復 | ✅ + 自定義 workflow |
| 歷史記錄保留 | 1 年 |
| 每週/月報告 | ✅ |
| 支援 | 專屬客戶成功經理 + Slack Connect |
| API 訪問 | 完整 API + Webhook |
| SSO / SAML | ✅ |
| SLA | 99.9% |
| 白標選項 | Phase 3 提供 |

### 超額計費
| 項目 | 價格 |
|------|------|
| 額外巡檢次數（每 100 次） | $5 |
| 額外網站（每站/月） | $39 |
| 額外歷史保留（每 30 天） | $10 |

### 年度折扣
- 年付方案：8 折（等同 2 個月免費）
- 多年合約：可談 7 折 + 優先功能開發

### 定價策略理由
1. **錨定效應**：Noibu / Contentsquare 企業級方案動輒數千美元/月，$149 極具競爭力
2. **價值可視化**：儀表板顯示「本月保護收入 $X」，讓客戶清楚看到 ROI
3. **免費試用**：14 天全功能試用，無需信用卡
4. **無風險轉換**：首月不滿意全額退費

| **企業直銷** | 銷售 | $800 | ⭐⭐ | P3 | 3 |

### 渠道策略詳細

#### 1. Shopify App Store（最高優先）
- **策略**：開發 Shopify App，讓商家一鍵安裝
- **優勢**：Shopify 商家主動搜尋解決方案，意圖明確
- **轉換率估計**：瀏覽 → 安裝 5%，安裝 → 付費 20%
- **關鍵字**：checkout monitoring, discount code validator, cart recovery

#### 2. 內容行銷 / SEO
- **策略**：建立「電商結帳優化」權威內容
- **內容主題**：
  - "如何預防 Shopify 結帳流程故障"
  - "黑五電商檢查清單 2026"
  - "折扣碼失效的隱藏成本"
- **渠道**：部落格、LinkedIn、電商社群媒體
- **預期**：6-12 個月後自然搜尋貢獻 30% 流量

#### 3. n8n Workflow Marketplace
- **策略**：上架預設的電商修復 workflow，引導用戶使用 CartRescue AI
- **優勢**：n8n 用戶已是自動化目標客群
- **內容**：Shopify 折扣碼自動修復、庫存檢查 workflow

#### 4. 電商社群經營
- **目標社群**：
  - 台灣：電商社群（Facebook）、Shopify Taiwan
  - 國際：r/ecommerce、Shopify Community、WooCommerce Slack
- **策略**：先提供價值（分享檢查清單、工具），再自然引入產品
- **KPI**：每週 3 篇有價值貼文，每月 1 場 AMA

#### 5. Agency 轉介計畫
- **策略**：與電商代營運 Agency 合作，他們推薦給客戶
- **誘因**：首年 20% 佣金 + Agency 專屬折扣碼
- **目標 Agency 類型**：
  - Shopify Partner Agency
  - 電商行銷公司
  - 技術顧問公司
